Changed management of ontologies and i/o routines. Ontology objects can be defined using arbitrary ontology IRIs and Entities and EntityCollections can be defined from any Ontology object. The inferred ontology `MagMO` is the default ontology and is stored in the Python package. All writing functions specify an `ontology_iri` for the ontology URL and `entity_iri` for the unique identifier in such ontology. All reading functions read the `ontology_iri` field to load a specific ontology, and define entities via the `entity_iri` identifier.
